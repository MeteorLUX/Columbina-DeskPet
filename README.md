# 哥伦比娅 · 桌面宠物

一个用 Python + Tkinter 写的 Windows 桌面宠物。她会住在你的任务栏上：自己散步、陪你聊天、给你唱歌、陪你计时学习，还会每天写日记记录你们做了什么。

> 角色为《原神》愚人众执行官「少女」哥伦比娅的同人形象，仅供学习交流。

---

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 🚶 自主走动 | 平时在任务栏上溜达，拖拽松手会掉下去再走回来（带物理效果） |
| 💬 三种对话模式 | 「本地台词库」离线检索原声；「本地 llm 模型」用 Ollama / LM Studio，**不花钱、不用 Key**；「DeepSeek 智能对话」接云端大模型 |
| 🎙 语音对话 | 语音：你直接说话，她听懂后回答（离线语音识别，不用联网） |
| 🔊 两种说话音色 | 「神经语音」微软在线合成，开箱即用；「本地语音」匹配你自己的原声音频（我自己找b站上别人录的游戏内声音替换） |
| 🎵 唱歌 | 随机想唱时会先问你想不想听；也可以点歌；支持暂停 / 继续 / 切歌 / 断点续唱 |
| 📖 学习计时 | 番茄钟式学习计时，学习中她陪你站定不乱跑，结束自动存记录、画柱状图 |
| 📔 日记 | 每天用她的口吻自动写一篇日记：学了多久、用了什么软件、什么天气、什么节日 |
| ⛅ 天气 / 节日 / 报时 | 问「现在几点」「今天天气怎么样」本地精准回答，不走大模型 |
| 👀 屏幕感知 | 可选：她知道你在用什么软件、看什么网站，还会主动搭话 |
| 🖱 帮你打开应用 | 说「打开 xxx」她帮你开，每次都会弹确认框，绝不自作主张 |
| ❤️ 摸头与好感度 | 摸摸头她会开心，好感度慢慢涨 |

## 🚀 快速开始

1. 安装 [Python 3.8+](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**
2. 双击 **`install.bat`** —— 自动装依赖；会询问是否下载离线语音识别模型（约 1GB，不下载则语音对话不可用，其余功能正常）
3. 双击 **`run.bat`** 启动
4. **右键点她**打开菜单，大部分设置都在菜单里

首次运行会自动生成 `config.json` 保存你的设置。

### 完整体验

- **智能对话**：在 [platform.deepseek.com](https://platform.deepseek.com/) 申请 API Key，填进 `config.json` 的 `deepseek_api_key`（或右键菜单切换对话模式后按提示操作）
- **语音对话**：install.bat 时选择下载模型；之后右键 → 「语音对话」打开
- **唱歌**：在项目目录新建 `music` 文件夹，放入你自己的歌曲（支持 mp3 / wav / flac / ogg / m4a）

## ⚙️ 配置说明（config.json）

| 字段 | 说明 |
|---|---|
| `master_name` | 她怎么称呼你（右键菜单也能改） |
| `dialogue_mode` | **对话内容从哪来**：`deepseek` = DeepSeek 云端 / `local_llm` = **本地 llm 模型**（Ollama / LM Studio，不花钱）/ `local` = 本地台词库（不调模型）|
| `deepseek_api_key` | DeepSeek API Key，`deepseek` 模式用；不填不影响其它模式 |
| `local_llm_url` | 本地模型接口地址（`local_llm` 模式用），默认 Ollama 的 `http://127.0.0.1:11434/v1/chat/completions` |
| `local_llm_model` | 本地模型名，如 `qwen2.5:7b` |
| `weather_city` | 天气城市，如 `武汉`；不填则她答不上天气 |
| `birthday` | 你的生日 `YYYY-MM-DD`，当天她会有特别的表示 |
| `speech_engine` | **出不出声**：`hybrid` = 只用原声（有音频才出声）；`edge` = 神经语音（什么都能念）|
| `speech_voice` | 神经语音的音色名（如 `zh-CN-XiaoxiaoNeural`） |
| `walk_enabled` / `topmost` / `scale` / `affinity` | 走动开关、置顶、缩放、好感度（菜单里都能改） |

### ⚠️ 两个维度是分开的（别混）

| 维度 | 由谁决定 | 选项 |
|---|---|---|
| **对话内容**从哪来 | `dialogue_mode` | DeepSeek 云端 / 本地模型 / 本地台词库 |
| **出不出声** | `speech_engine` | 只用原声（没音频就静音）/ 神经语音（都念）|

> **语音引擎不影响对话内容。** 用「只用原声」也能跟真 LLM 对话——
> 只是 LLM 生成的话库里没有，所以**不出声、只冒气泡**。
> 想让她把 LLM 的话也念出来，就把 `speech_engine` 切成 `edge`。

## 🕹 使用方法

**右键菜单是总入口**：对话模式、语音对话、音色、唱歌、学习、日记、屏幕感知、走动开关、置顶……都在里面。

### 对话：三种模式

右键 →「💬 对话模式」，选一个：

| 模式 | 花钱？ | 需要什么 | 适合 |
|---|---|---|---|
| **DeepSeek 云端** | 有免费额度，超了很便宜 | 填 `deepseek_api_key` | 回复质量最好 |
| **本地模型** | **完全不花钱** | 本地跑 Ollama / LM Studio | 不想花钱、想离线 |
| **本地台词库（离线）** | 不花钱 | 什么都不用 | 只想要她的原声，不需要真对话 |

选完以后：右键 →「显示/隐藏输入框」，打字回车即可。

**用本地模型（不花钱的那条路）**：

```bat
:: 1. 先把本地模型服务拉起来（便携版在 ollama\ 里，装好就有）
start-ollama.bat

:: 2. 拉一个模型（约 4.7 GB，存到 ollama-models\，不占 C 盘）
ollama\ollama.exe pull qwen2.5:7b

:: 3. 确认它在
ollama\ollama.exe list

:: 4. 桌宠里右键 →「对话模式」→「本地模型（Ollama/LM Studio）」
::    再「⚙️ 设置本地模型…」点「测试连接」验证
```

- Ollama 地址：`http://127.0.0.1:11434/v1/chat/completions`
- LM Studio 地址：`http://127.0.0.1:1234/v1/chat/completions`
- 本地模型**不需要 API Key**，请求也不出你的电脑
- 面版里的「测试连接」会真的发一次请求，连不上会直接告诉你原因
- 想让服务开机自启：把 `start-ollama.bat` 的**快捷方式**放进
  `Win+R` → 输入 `shell:startup` → 回车，打开的那个文件夹

> **为什么用便携版**：安装版会装到 C 盘，还会往 `C:\Users\<你>\.ollama`
> 写密钥。便携版解压在项目里，配合 `OLLAMA_MODELS` 和 `HOME` 两个环境变量
> 重定向，**模型权重和密钥全在 E 盘**。`start-ollama.bat` 已经设好了。

### 本地台词库是干什么的

**217 句她的原声**（从视频里提取的真人配音）。它**只负责她主动开口的场合**：

| 场合 | 用哪 |
|---|---|
| **你主动跟她说话** | 真 LLM（DeepSeek 或本地模型）|
| **她自己待机搭话**、整点报时、摸头 | **本地台词库**（保证有声音）|
| 你主动选了「本地台词库（离线）」模式 | 台词库（你自己的选择）|

> 也就是说：想真聊天，**把 `dialogue_mode` 设成 `deepseek` 或 `local_llm`**；
> 台词库只在她"自己找话说"时兜底，保证一开口就有声。

### 其它
- 问时间、日期、天气这类问题，她本地精准回答，不会编

### 语音对话
- 右键 → 「语音对话」开启后直接说话即可，全双工（她说话时你也能插话）
- 也可以用语音下指令：「唱首歌」「我想听你唱歌了」「开始学习」「暂停学习」「结束学习」「打开 计算器」……
- 「说话音色」菜单里选「神经语音」或「本地语音」，切换时音色自动适配

### 唱歌
- 她偶尔会自己想唱，先弹出气泡问「想听我唱歌吗？」，选「想」或「不想」（选不想则 10 分钟内不再打扰）
- 随时说「唱首歌 / 点歌 / 来首歌」手动点歌
- 播放中可用口令：「暂停」「继续唱」「上一首」「下一首 / 换一首」「停止」
- 歌曲渐入渐出，停在整句歌词上；下次再唱从停下的地方继续，不会从头唱
- 歌曲文件请放在项目目录的 `music/` 文件夹（自备音乐，不入库）

### 学习计时
- 右键 → 「学习」打开面板：开始 / 暂停 / 结束 / 查看记录
- 也可以直接说「开始学习」；学习中她会站定陪你，45 分钟会提醒休息
- 记录页有日列表和周 / 月柱状图

**记录不会丢**（这块以前有 bug，现已修好）：

| 情况 | 行为 |
|---|---|
| 点「结束学习」 | 立即写入 `study_records.json` |
| **直接关掉程序 / 崩溃** | 学习期间**每 15 秒**自动落盘一次（`STUDY_AUTOSAVE_SEC`），退出时再结算成一条正式记录 |
| **重启后** | 发现上次还在学习中 → **自动接着计时**，并告诉你「上次学到 X 分钟」 |
| 暂停 / 继续 | 时长**累加**，暂停的时间不计入 |
| 开始时间 | 记的是**最初**那次开始的时刻，不受暂停/继续影响（以前会被算错，导致当日列表里看不见） |

> 判定标准：有效学习 **≥ 60 秒**（`STUDY_MIN_SAVE_SEC`）才记录。
> 短于这个只提示「这次太短了」，不写文件。

**关于"最后那几秒算不算"**（说清楚，免得你对不上账）：

- 计时**结束的时刻**是程序退出的那一刻（按原样遵守"停止 = 停止计时"）。
- `live` 状态里存的秒数是**每 15 秒刷新一次**的。所以如果程序被**强杀**
  （任务管理器结束进程、断电），恢复时看到的是最后一次自动保存的数字，
  **最后 0~15 秒不计入**。
- 如果是**正常退出**（右键 → 退出，或关掉控制台窗口），退出时会现场结算
  到那一刻，**一秒不差**。


### 屏幕感知与打开应用
- 右键 → 「让她知道我在用什么」开启后，她能知道你前台在用什么软件 / 看什么网站，偶尔插句话；「她在看什么」面板可查看当前状态
- 活动记录只保存在本地，且每周自动重置
- 对她说「打开 xxx」：她弹出确认框显示将要打开什么，你确认后才执行；「管理软件路径」可登记常用软件

### 摸头与好感度
- 用鼠标在她头上轻轻晃一晃就是摸头；好感度在右键菜单「查看好感度」

## 🔧 自定义与自我修正

所有台词、提示词都集中在 **`lines.py`** 一个文件里（结构清晰、带注释），改完重启即生效；右键菜单「重新加载本地对话」可立即刷新对话库。

### 1. 改台词 / 加台词
- 打开 `lines.py`，按分区找到对应台词直接改：人设提示词、默认对话库、摸头、唱歌、学习、天气、日记素材……
- 本地对话库运行时实际读取 `dialogues.txt`（每行一句，`#` 开头是注释）；该文件不存在时自动用 `lines.py` 内置的兜底库
- 改完 `dialogues.txt` 后右键 → 「重新加载本地对话」立即生效，不用重启

### 2. 本地语音勘误（本地语音用户）
本地原声依赖「台词文字 → 音频」的匹配表（`voice-lines.json`，由语音识别自动生成）。识别难免有错别字，修法：

1. 打开 `voice-fixes.json`，加一条：`{"听错的原文": "正确文字"}`
   - 值写空串 `""` 表示**删除整句**（只在整句完全一致时删，防止误删）
   - 配对是子串替换，**尽量写长一点**（如 `"和愚人中的两般经历"` 而不是 `"愚人中"`），避免误伤别的句子
2. 运行 `python _apply_voice_fixes.py`，秒级把勘误套进语音库
3. 若这句也在 `lines.py` / `dialogues.txt` 台词库里，把同一句改成一致

### 3. 自建原声语音库（进阶）
想让她用你自己准备的一批原声 wav 说话：

1. 把音频（wav）放进 `voice/` 目录
2. 跑 `_split_voice.py` 切句 → `_transcribe_voice.py` 离线转写生成 `voice-lines.json` → `_rebuild2.py` 重建 `lines.py` / `dialogues.txt`
3. 之后说话时她优先精确匹配台词用原声念，匹配不到的自动落到神经语音

> 不弄原声库也完全不影响使用：神经语音开箱即用。

## ❓ 常见问题

| 问题 | 处理 |
|---|---|
| 启动时提示缺 Pillow / requests 等 | 重跑 `install.bat` |
| 语音对话不可用 | install.bat 时没下模型：删除 `voice-model/` 后重跑 install.bat 选 Y |
| 唱歌功能不可用 | 缺 miniaudio：重跑 `install.bat`；确认 `music/` 里有音频文件 |
| **她只从台词库里配对，不真对话** | 你的 `dialogue_mode` 是 `local`。右键 →「对话模式」改成 **DeepSeek 云端** 或 **本地模型**。`local` 的定义就是"从库里挑"，它本来就不调模型 |
| **切了 LLM 模式还是不真对话** | 曾经有个 bug：`speech_engine='hybrid'` 会把内容强行拉回台词库。已修复（现在两个维度彻底分开）。若还这样，跑 `python tests\_speech_regress_test.py` 看 T13 是否通过 |
| 智能对话 401 / 不回复 | `config.json` 里 `deepseek_api_key` 未填或失效（改完不用重启） |
| **本地模型没回应** | 按顺序查：① `ollama list` 看服务在不在跑 ②「⚙️ 设置本地模型…」→「测试连接」看具体报错 ③ 模型名要和 `ollama list` 里的一致（如 `qwen2.5:7b`）④ 首次调用模型要加载进显存，可能等 10~30 秒 |
| 神经语音没声音 | 检查网络（edge-tts 在线合成）；切换引擎后音色会自动适配 |
| **LLM 回复只有气泡没声音** | 这是设计如此：`speech_engine='hybrid'` 时**只用原声**，LLM 生成的话库里没有 → 静音。想让她念出来就把引擎切成 `edge`（神经语音） |
| 想改她说的某句话 | 改 `lines.py`（或 `dialogues.txt`），见「自定义与自我修正」 |
| 想打包成 exe | 跑 `pack.bat`（生成在 `dist/`） |
